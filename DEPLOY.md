# Деплой бота на Render (бесплатно)

## Шаг 1. Залить код на GitHub

1. Создай новый репозиторий на github.com (например, `diet-bot`)
2. В папке проекта:
```
git init
git add .
git commit -m "init"
git branch -M main
git remote add origin https://github.com/ТВОЙ_НИК/diet-bot.git
git push -u origin main
```

## Шаг 2. Создать сервис на Render

1. Зайти на **render.com**, войти через GitHub
2. **New** → **Web Service**
3. Выбрать репозиторий `diet-bot`
4. Render сам подхватит настройки из `render.yaml` (Blueprint). Если спросит вручную:
   - **Runtime**: Python 3
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python bot.py`
   - **Plan**: Free

## Шаг 3. Задать переменные окружения

В настройках сервиса → **Environment** добавить:
- `BOT_TOKEN` — токен от @BotFather
- `GEMINI_API_KEY` — ключ с aistudio.google.com
- `PYTHON_VERSION` — `3.12.3` (обязательно! иначе Render возьмёт Python 3.14, под который ещё нет готовых пакетов, и билд упадёт с ошибкой сборки pydantic-core/maturin)

## Шаг 4. Деплой

Нажать **Create Web Service** (или **Deploy**). Render соберёт и запустит бота.
Через пару минут в логах должно появиться `Health-check сервер запущен на порту ...` и `Start polling`.

## Важно про бесплатный тариф Render

1. **Сон при бездействии.** Бесплатный Web Service засыпает после 15 минут без входящих HTTP-запросов. Но так как бот работает через polling (сам стучится в Telegram), а не ждёт входящих запросов, реальный трафик к нему не идёт — сервис может засыпать, и бот перестанет отвечать, пока не "разбудится".
   - **Решение**: подключить бесплатный пинг-сервис (например, **UptimeRobot** или **cron-job.org**), который каждые 5-10 минут дёргает URL твоего сервиса (Render выдаёт публичный адрес вида `https://diet-bot-xxxx.onrender.com`). Health-check эндпоинт (`/`) уже есть в коде — как раз для этого.

2. **База данных не сохраняется между деплоями.** На бесплатном тарифе файловая система эфемерна — при каждом передеплое или перезапуске сервиса файл `diet_bot.db` (профили пользователей) обнулится.
   - **Решение**: если это критично, можно подключить бесплатную PostgreSQL от Render (есть бесплатный тариф с ограничением по времени жизни) или Supabase — скажи, если нужно, перепишу `database.py` под Postgres.

## Проверка

После деплоя написать боту в Telegram `/start` — должен ответить.
